01
主攻图谱：政策知识图谱

政策知识图谱自动化构建

企业方提供政策文本爬取能力
负责设计从政策文档到结构化知识图谱的自动化构建链路
涵盖本体生成、条款抽取、图谱入库与合规输出四个环节。

01
政策文档采集
企业爬虫提供 PDF、TXT、网页正文及发文主体、地区、日期等元数据，形成统一输入层。
02
LLM 驱动本体生成
由大模型读取文档样本，自动归纳实体类型、关系类型与字段 Schema，无需人工预先定义本体。
03
条款切分与抽取
按段落和条款分块，抽取政策条款、适用对象、监管部门、约束条件及条款间依赖关系。
04
图谱构建与质检
批量写入图谱引擎，补充冲突、依赖、引用来源和可追溯证据，并做结构完整性校验。
05
跨图谱合规输出
将政策约束以接口形式输出给服务推荐、机构准入判断和问答系统，形成跨图谱约束层。
企业提供
  • 政策法规爬取工具和原始文档库
  • 发文主体、时间、地区、主题标签等元数据
  • 已有 Web 应用或图谱可视化容器
我们负责
  • 政策领域 Schema 设计与 LLM 本体自动生成模块
  • 条款切分、实体关系抽取、批量入图流水线
  • 依赖、冲突、适用边界规则建模与可追溯质检
企业后续可基于该图谱的接入方向
  • 企业后续可将其用于约束服务资源图谱中的机构资质、服务范围和准入规则
  • 企业后续可据此限定中西医融合 Demo 中可展示的服务路径与建议边界
  • 企业后续也可将其作为老人、设备、辅具等图谱的合规过滤条件来源

02
主攻图谱：医疗知识图谱 + 中医知识图谱

中西医知识图谱融合 Demo

中西医知识图谱融合的核心技术挑战是实体对齐
找出跨体系图谱中指向同一真实概念或高度相关概念的实体对
设计了一套三阶段 LLM 驱动的对齐方案直接由大模型驱动端到端对齐流程

无需人工标注种子对 无需单独训练对齐模型 适合中西医双重异构场景
Stage 1
信息摘要统一
将中西医两侧实体统一转换为结构化摘要，消除语言和表述风格差异，为后续编码提供一致输入。
  • 提取实体名称、属性三元组、关系三元组三类信息；
  • 将中医文言或术语密集描述转成现代汉语或英文摘要；
  • 西医实体同步生成统一格式摘要，保证两侧编码空间可比较。
Stage 2
嵌入与特征融合
对名称、属性、关系三类摘要分别编码，再拼接成统一实体表示，三路特征互补。
E = Ename||Eattribute||Erelation
  • 属性信息通常贡献最大，携带疾病表现、症状和干预方式等关键语义；
  • 对于名称差异悬殊的实体（如"肝郁气滞"），属性与症状层面的重叠更为关键；
  • 三路融合比单纯关键词匹配更适合跨体系语义映射。
Stage 3
候选实体判别
先基于向量相似度召回候选集，再由 LLM 分层判别，避免设置固定阈值，提升边界案例的鲁棒性。
  • 按余弦相似度为每个实体召回 Top-10 候选。
  • LLM 逐层引入名称、属性、关系信息依次判断，信息充分即输出结果。
  • 对无法确认等价的边界案例，输出 associatedWith 并送人工复核。
企业提供
  • 中医和西医开源数据集的既有整理结果
  • 现成的可视化 Web 应用或展示容器
  • 典型业务场景和想展示的问题模板
我们负责
  • 设计并实现三阶段 LLM 驱动对齐流水线
  • 完成摘要生成、三路编码、候选召回与分层判别
  • 围绕高血压管理、睡眠障碍等典型场景完成局部融合与 Demo 搭建
  • 定义 sameAs 与 associatedWith 两类输出，保证演示可解释性
后续可扩展方向
  • 将局部对齐扩展至更多慢病与康养场景（如营养干预、运动管理）
  • 接入真实患者数据后，对齐结果可直接驱动个性化 RGPS 服务路径推荐
  • 融合图谱可作为语义底座，为上层大模型问答提供可追溯的知识支撑
